# Chococo（AIスイーツ×ドリンクペアリングアプリ）

食べたいスイーツに合う飲み物（主にコーヒー）をAIが提案してくれるWebアプリです。あわせて食べたスイーツの記録をインスタグラム風のUIで残せる機能を提供し、日々のスイーツ体験を記録・振り返れるサービスを目指します。

スクール課題として、技術要件であるJava（Spring Boot）・Reactを用いて、要件定義・設計・実装の各フェーズをAI支援ツール（Claude Code）とともに進めながら開発しています。

## 差別化ポイント

- **PostCoffee**・**root C MATCH**：質問に回答する診断型のコーヒー提案。Chococoはスイーツ名からの自由入力起点。
- **CoffeePad**：記録＋カレンダーは近いが、ペアリング提案機能は持たない。

Chococoは「食べたいスイーツを起点に、AIが理由つきでペアリングを提案し、その結果を記録として残せる」点が差別化ポイントです。

## 機能（MVP）

| No. | 機能 | 概要 |
|---|---|---|
| 1 | ユーザー認証 | メールアドレス＋パスワードによる新規登録・ログイン。JWTアクセストークン＋リフレッシュトークン方式。 |
| 2 | ペアリング提案 | スイーツ名を入力すると、Anthropic Claude APIがコーヒー豆マスタ10種の中から最適な1つを選び、理由とあわせて提示する。1ユーザー1日10回まで（JST基準）。 |
| 3 | 記録の保存 | 写真・スイーツ名・記録日・感想を記録として保存する。AIペアリング提案経由の場合は提案結果もスナップショットとして保存できる（提案なしでの記録単体保存も可）。 |
| 4 | 記録一覧表示 | 保存した記録をカレンダー形式（インスタグラム風）で月単位表示する。同日に複数記録がある場合は件数バッジで表示。 |
| 5 | 記録の編集・削除 | 自分が保存した記録のスイーツ名・記録日・写真・感想を編集、または記録自体を削除できる（本人のみ）。 |

詳細は[要件定義](docs/requirements.md)・[機能設計](docs/functional-spec.md)を参照。

### スコープ外（今回は実装しない）

- パスワードリセット・メールアドレス確認
- 記録の公開・他ユーザーからの閲覧（全記録は本人のみ閲覧可能）
- 逆方向のペアリング提案（コーヒー→スイーツ）、紅茶等コーヒー以外への対応拡大
- スイーツ写真のS3への本格保存（v1はEC2ローカルディスク）
- Instagramとの連携

## 技術スタック

| レイヤー | 技術 |
|---|---|
| フロントエンド | React 19 + TypeScript + Vite、CSS Modules、fetch API |
| バックエンド | Java 21 + Spring Boot 3.5系、Spring Security（JWT認証）、Spring Data JPA |
| データベース | MySQL 8.0（ローカルはDocker、本番はAWS RDS） |
| AI連携 | Anthropic Claude API（`claude-haiku-4-5`。Spring `RestClient`で直接HTTP呼び出し） |
| インフラ | AWS EC2（t3.micro）+ RDS（無料枠内での運用が前提） |

選定理由・バージョン詳細は[技術スタック](docs/tech-stack.md)を参照。

### フロントエンドプロトタイプの起動方法

```bash
cd frontend
npm install
npm run dev
```

`http://localhost:5173` で起動します（ポート固定。[技術スタック](docs/tech-stack.md)参照）。全画面の状態はメモリ上のモックデータのみで管理しており、リロードすると初期状態に戻ります。
